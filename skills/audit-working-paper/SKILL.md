# 生成工作底稿與查核意見

> 四階段結構源自 vault `CLAUDE.md`「工作底稿生成規則」及 `docs/working-paper-principle.md`（1150826 修訂）。
> **金額認定與取捨規則**依 115/11/8 河川疏浚案反覆修正結果增訂（第肆、伍節），為本技能最重要部分。
> **先備條件**：已完成 `audit-secondbrain` 安裝，vault 內有 `資料處理/3.查核意見/` 案例可參考。

## 壹、工作流程

### 第一步：取得查核事實

使用者說：
```
請幫我根據 [主題] 生成工作底稿（或查核意見），
相關資料在 資料蒐集/ 及 資料處理/3.查核意見/ 中。
```

你應：
1. 讀取 `資料蒐集/` 的查核資料（契約、磅單、公文、公告、資料庫）
2. 讀取 `資料處理/3.查核意見/` 同類型案例，確認體例
3. 逐項確認「契約／法令有無訂罰則」、「金額能否由卷內資料直接算出」
4. 依四階段結構產出；對外查核意見另依附錄一體例
5. 產出 MD 檔；使用者要求時另產出 WORD 檔
6. 儲存至 `資料庫建置及產出/工作底稿/` 或專案指定資料夾

### 第二步：角色與語氣

- 以「資深審計人員」角度撰寫
- 正體中文、白話、審計人員口吻
- 每個數字都要有來源與算式
- 不確定者寫「允待查明」，不以推測補足

## 貳、四階段結構

### 1. 標題
- 粗體、**200 字內**
- 首段：查核標的項目（機關＋事項）
- 中段：查核事實與缺失摘要（含關鍵金額）
- 尾段：「允待／允宜／允應……，以……。」小結，並**呼應擬議處理意見**
- 範例：「宜蘭縣政府辦理○○作業，115年4月14日未達契約每日出貨量下限8,000公噸，差額3,799.16公噸，應計罰金3萬7,992元，允待依約計罰並查明有無免罰事由(監督)」

### 2. 依據
- 引用**行為時**之法令／規定／函文／契約條款
- **全段文字截錄，不摘要**
- 依查核事實發生時序及缺失順序對應擇選
- 契約、施工補充說明書、詳細價目表、公告為主要依據；民法、道路交通管理處罰條例等通則僅輔助
- 引用前檢視適用性：不適用者刪除，並檢查相關援引一併刪除（例如未達查核金額之小型工程不適用政府採購法第63、70條；縣府品質規定已明定扣點者優先於勞務契約第9條及行政程序法第51條）
- 縣府品質管制及監造品質查證規定應載明第幾點第幾項，並以扣點／罰款為主要依據，詳述違約日期、規定應完成日期、逾期天數及金額計算式

### 3. 查核事實
架構：**機關主體 ＋ 查核標的（規模／金額）＋ 執行情形／現況（含大事記）＋ 缺失分析**

- 缺失分析以轉折語氣開頭：「惟查……核有……疏失」或「核欠妥適」
- 每點缺失須對應依據之具體條項（例如「契約第14點」、「採購法第26條」）
- 涉及扣罰金額者，詳述行為日期、規定應完成日期、逾期天數及計算式
- 段落以「經查／次查／復查／另查」串接，避免表格

### 4. 擬議處理意見
- **200 字內**
- 與標題尾段呼應
- 以「綜上，本案核有……等情事」開頭，並分項對應缺失點
- 可用「綜上／鑑於」結合查核事實推論總結

### 5. 三者呼應總則
依據、查核事實、擬議處理意見三者須一致：依據按事實時序及缺失順序擇選；缺失每點對應依據條項；擬議以缺失綜整開頭並分項對應。

## 參、查核意見（對外）與工作底稿（內部）之區別

| 項目 | 工作底稿 | 查核意見／查明處理事項 |
|---|---|---|
| 用途 | 內部查核紀錄、支撐意見 | 對外函文附件 |
| 內容 | 可含查核過程、抽核範圍、未採用之分析 | 僅列可認定之事實與金額 |
| 體例 | 四階段，可較詳細 | 一頁式連續敘述，**無表格、無表號、無生成紀錄、無版本紀錄、無前版對照** |
| 金額 | 可列分析結果（含推估） | **僅列契約訂有罰則且卷內可直接算出者** |

查核意見標準體例：
```
---frontmatter（title/date/tags/source）---
# 結論式標題（尾註「(監督)」或「(洞察)」「(前瞻)」）
依據……（契約條文全文、法令）
經查……（機關、規模、事實、算式、缺失）
次查／復查／另查……（其餘事實，無異常者摘要一句）
綜上，擬……（計罰、追補、查明事項）
```

## 肆、金額認定與罰則取捨（1151108 修訂，必守）

1. **只列契約或法令訂有罰則、且可計金額之項目。** 契約未訂罰則者，不得列為應計罰金或應追補金額。
   - 例：補充說明書第21點僅規定「廠商應負責裝、卸作業」，未訂罰金 → 出場未達 35 公噸之 3 趟不得計罰。
2. **不得以「原可增加」推估列入追補。** 土石未運出、機關無短收價款者，不得以「如補裝原可增加售價」列為應追補金額。
3. **不得以統計推測代替契約定義。** 以中位數、常態值、0.5 公噸門檻等統計方法認定異常，如契約、規範未定義該異常，屬推測，應刪除。
   - 例：契約無「空車重異常」定義 → 空車重較常態值高 0.5 公噸之 318 趟不得列為缺失或短計價款。
4. **契約僅對下限訂罰則者，不得以超過上限計罰。** 僅得列為契約妥適性檢討，且不列入金額。
   - 例：第14點僅就「未達 8,000 公噸」訂罰則，對超過 12,000 公噸未訂 → 153 日逾上限不得計罰。
5. **金額必附算式。** 格式：「差額×單價×罰則比率＝金額」，並註明四捨五入。
   - 例：8,000－4,200.84＝3,799.16 公噸；3,799.16×10＝37,991.6 元；×100%＝37,991.6 元≒3萬7,992 元。
6. **只列卷內資料可直接算出者。** 需再向機關查證始能確定者（責任歸屬、是否合理改裝、是否核准），不列入金額，移至擬議請機關查明。
7. **同一事實有多種認定基準時，應並列說明。** 例如契約每日出貨量為 3,000～5,000 公噸之區間，應敘明以 3,000 計為 0 日、以 5,000 從嚴認定為 1 日，並請機關確認認定基準，不得逕自擇一。

## 伍、事實敘寫與文字體例（1151108 修訂）

8. **無異常事項摘要即可。** 經查證無異常者（例如車籍限重 277 處均為 35.000 公噸、通行卡與車籍相符），以 2～3 句「此部分尚無異常」帶過，不逐項鋪陳，以免稀釋真正缺失。
9. **法令依據以契約為主。** 契約、施工補充說明書（視同契約）、詳細價目表、公告優先；通則性法律僅輔助，且不得引用不適用條文。
10. **契約條次不得混引。** 同一機關不同年度、不同案號之補充說明書條次不同（例如蘭陽溪第14點、東澳溪第（十四）點、白米溪「貳、２」），應逐案確認原文，不得互相援引。
11. **免罰要件須逐項檢視。** 契約定有「除歸責於機關、申購廠商或經主辦機關認可者外」者，應敘明卷內有無免罰事由及施工日誌記載，以「卷內未見……」具體表述；並就未依規定記載者加註「核有……疏失」。
12. **沿用契約用語。** 契約稱「罰金」者用罰金、稱「違約金」者用違約金；「罰鍰」為行政罰，不可混用。
13. **對外文稿體例從嚴。** 一頁式連續敘述；不設表格、表號、生成紀錄、版本紀錄、前版對照、彙整資訊；不用 `{{ }}` 等模板殘留。
14. **標題與擬議各 200 字內且互相呼應。** 擬議以「綜上，本案核有……」開頭，分項對應缺失。

## 陸、交稿前檢核清單

- [ ] 標題 200 字內，含機關、事項、缺失、金額、「允待…」小結
- [ ] 依據為行為時法令，全文截錄未摘要，且條文確實適用本案
- [ ] 契約條次逐案核對，未與其他案混引
- [ ] 每一金額均有算式及四捨五入說明
- [ ] 所計罰項目均為契約或法令明定有罰則者
- [ ] 未以統計推測或「原可增加」推估列為金額
- [ ] 無異常事項已摘要處理，未逐項鋪陳
- [ ] 免罰要件已檢視，並敘明卷內有無記載
- [ ] 擬議 200 字內，與標題尾段呼應
- [ ] 對外文稿無表格、無表號、無版本／生成紀錄
- [ ] 引號「」、括號（）對稱，無模板殘留
- [ ] 金額、車次、噸數與來源資料一致（建議以程式复核）

## 柒、查核意見分類與提取（參考）

**四層分類**（歸檔至 `資料處理/3.查核意見/`）：
- 第一層：查核主題（工程品質、採購程序、財務管理、內部控制等）
- 第二層：建議事項、查明處理事項、注意事項
- 第三層：洞察、前瞻、監督
- 第四層：查核意見標題及全文，末尾註記「（截取自：報告名稱）」

**提取方法**：定位「查核意見」章節 → 依 `**一、**`、`**二、**` 分割 → 每項獨立 MD → 四層歸檔。

**總整理／明細**：`/資料處理` 完成後自動更新 `查核意見總整理(YYYYMMDD).md` 及 `查核意見明細(YYYYMMDD).md`（以本文 MD5 去重）。

## 捌、產出格式

- **MD**：四階段結構，frontmatter 含 title、date、type、tags
- **WORD**：使用者要求時，以 docx 產出同結構
- 儲存：`資料庫建置及產出/工作底稿/`，或使用者指定之專案資料夾
